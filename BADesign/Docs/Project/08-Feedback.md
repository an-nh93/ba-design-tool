# Feedback

User gửi góp ý, lỗi, hoặc đề xuất. Super Admin xử lý ở màn quản lý.

## Gửi

`Pages/Feedback.aspx`. Nội dung chữ, có thể kèm ảnh (`Content/FeedbackImages/...`). Gửi xong user thấy lịch sử của mình.

## Quản lý

`Pages/FeedbackManage.aspx`. Danh sách góp ý, trạng thái xử lý, người gửi. Chỉ vai trò quản trị.

## Ý tưởng

Feedback là kênh sản phẩm, không phải audit kỹ thuật. Ảnh lưu file, bài ghi DB. Không trộn với Audit Log (audit là hành động trên database).
