# BADesign — mục lục cho AI

Đọc file của phần cần sửa. Phần Builder nằm trọn trong một file.

| [02-Dang-nhap-va-phan-quyen.md](02-Dang-nhap-va-phan-quyen.md) | Login, role, permission, user |
